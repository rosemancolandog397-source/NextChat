# 服务端 API Key 安全模式

网页生产模式默认启用服务端密钥，不能通过 `SERVER_ONLY_API_KEY=0` 关闭。开发模式可设置 `SERVER_ONLY_API_KEY=1` 提前验证。静态导出和桌面应用不支持此服务端代理模式，保留原有行为。

在本机 `.env.local` 或部署平台的服务端环境变量中，由项目所有者配置：

```dotenv
SERVER_ONLY_API_KEY=1
OPENAI_API_KEY=<你的部署专用 OpenRouter Key>
BASE_URL=https://openrouter.ai/api/v1
CODE=<高强度访问口令>
```

不要直接复制占位符运行，不要使用 `NEXT_PUBLIC_` 前缀，不要把实际密钥填入 README、截图、聊天或版本库。`BASE_URL=https://openrouter.ai/api` 也受支持；服务端会避免重复拼接 `/v1`。保留现有 DeepSeek 模型 ID 和 OpenAI 兼容服务商配置，无需改用 DeepSeek 官方 API。

安全模式下，浏览器只向本站 `/api/openai/v1/chat/completions` 发送模型请求，服务端再向 OpenRouter 注入密钥。设置页和登录页隐藏密钥输入，URL 快速导入设置被禁用，客户端不会使用旧的浏览器密钥或自定义 OpenRouter 地址；服务端拒绝客户端自带密钥。共享密钥不会通过 `/api/config` 返回，也不写入前端构建配置。

本次修复不会自动读取或迁移浏览器原有密钥，不会删除 IndexedDB、localStorage、聊天和需求草稿。旧浏览器中曾保存的个人密钥仍属于历史风险；所有者应完成服务端配置后，再自行轮换旧密钥并处理历史备份及日志。新模式不等于已清理历史副本。

未配置服务端密钥时会明确报错，不会回退到浏览器旧密钥。生产构建应在环境变量设置完成后重新构建、启动；本阶段没有设置真实密钥、执行部署或调用付费模型。

本阶段移除了 API 路由中的动态日志，避免输出认证头、访问口令、请求体、含密钥的 URL 和原始异常；错误响应使用固定文本。公开模式下禁用了可由客户端指定目标地址的通用代理，防止共享密钥被转发至伪造域名。普通聊天、工作台澄清和 PRD 仍复用现有服务商调用能力。

访问限速、消费预算、依赖漏洞、云同步/分享接口权限及隐私治理不在本阶段内，不能据此认定项目已经可以无保护公开上线。
